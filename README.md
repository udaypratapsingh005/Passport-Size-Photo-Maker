# 📸 Passport Size Photo Maker

A modern and easy-to-use web application that helps users create passport-size photographs quickly and conveniently from their own images.

The application provides a simple workflow to upload, preview, customize, and prepare passport-size photos through a clean and responsive interface.

## 📌 About The Project

Creating passport-size photographs often requires visiting a photo studio or using complicated image-editing software.

**Passport Size Photo Maker** aims to make this process simpler by providing a browser-based solution where users can upload an image and prepare a passport-size photo through an intuitive interface.

This project was developed using React with a focus on:

* Clean UI design
* Reusable components
* Responsive layout
* Maintainable code
* DRY (Don't Repeat Yourself) principles
* Smooth user experience

## 🎯 How To Use

1. Open the Passport Size Photo Maker website.
2. Upload an image from your device.
3. Preview the uploaded photograph.
4. Customize the photo according to the available options.
5. Generate the passport-size photo.
6. Download or use the final output.

The project was developed with an emphasis on:

The UI is divided into reusable and manageable React components.

### DRY Principle

Repeated UI logic and styling are organized to reduce unnecessary duplication.

### Responsive Design

The interface is designed to work across desktop, tablet, and mobile screen sizes.

### User-Friendly Experience

The application focuses on keeping the photo creation process simple and easy to understand.
